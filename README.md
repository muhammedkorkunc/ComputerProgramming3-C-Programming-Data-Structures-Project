# ⚡ Bilgisayar Programlama 3 (BP3) — Modüler C ve Veri Yapıları Mimarisi

### Dinamik Bellek Tahsisi, Modüler C Mimarisi ve Makefile Otomasyonu

Bu depo; Fatih Sultan Mehmet Vakıf Üniversitesi Bilgisayar Mühendisliği lisans programı **Bilgisayar Programlama 3 (BP3)** dersi kapsamında geliştirilen modüler C projesini, Makefile derleme otomasyonunu ve teknik proje raporunu barındırmaktadır.

---

## 🛠️ Modül ve Dosya Hiyerarşisi

| Dosya                       | Açıklama                                                                                    |
| :-------------------------- | :------------------------------------------------------------------------------------------ |
| **`main.c`**                | Program giriş noktası, girdi akışı ve operasyonel modül koordinasyonu.                      |
| **`Proje1.c` / `Proje1.h`** | Çekirdek veri yapıları, pointer aritmetiği, dinamik bellek yönetimi ve algoritmik işlevler. |
| **`makefile`**              | GCC tabanlı optimizasyonlu derleme ve linkleme betiği.                                      |
| **`korumali_rapor/`**       | Proje gereksinim föyü ve detaylı teknik analizleri içeren filigranlı dokümantasyon.         |

---

## ⚙️ Derleme ve Çalıştırma

Projeyi derlemek ve test etmek için terminalde şu komutları çalıştırmanız yeterlidir:

```bash
make
./program.exe
```
